Pertanyaan Umum

Jawaban untuk hal-hal yang paling sering ditanyakan.

Tergantung jenis layanan. Logo 1–3 hari, desain cetak 1–2 hari, manual tracing 1–2 hari, template Canva 2–4 hari, mockup 1 hari. Semua bisa lebih cepat dengan paket express.
Tergantung layanan: Logo → AI/CDR/SVG + PNG/JPG. Desain cetak → PDF CMYK + JPG/PNG. Tracing → AI/CDR/SVG. Canva → link editable. Mockup → PNG/JPG HD.
DP 50% di awal pengerjaan, pelunasan setelah desain disetujui dan sebelum file final dikirim. Pembayaran via transfer bank atau e-wallet.
Revisi dilakukan sebelum file final. Jika ada perubahan setelah file dikirim karena kesalahan di pihak kami, kami tangani gratis. Perubahan permintaan baru akan dikenai biaya tambahan.
